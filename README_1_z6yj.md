# Claude 숨은 기능 가이드

처음 쓰는 사람이 눌러볼 만한 Claude 기능 세 가지를 소개하는 한 페이지짜리 가이드입니다. 위쪽 버튼으로 한국어와 English를 바꿀 수 있고, 카드의 버튼을 누르면 시작 방법과 바로 따라 해볼 문장(복사 버튼 포함)이 펼쳐집니다.

## 다루는 기능
- 사진을 올리고 그냥 물어보기
- 말로 외국어 연습하기 (음성 모드)
- 한 문장으로 작은 앱 만들기 (아티팩트)

## 왜 만들었나
기능이 있어도 쓰는 사람이 모르면 도입은 일어나지 않습니다. 임상검사실에서 여러 부서에 새 시스템을 교육하며 본 문제를, Claude 사용자 교육의 첫 단계인 "일단 한 번 눌러보게 하기"로 작게 풀어 봤습니다.

## 만든 방식
- Claude와 함께 만들었습니다. 기능 선정, 공식 문서 확인, 문구 판단은 제가 했고, 초안 작성과 HTML 구현은 Claude가 도왔습니다.
- 내용은 Claude 공식 도움말과 대조했고, 확인일은 2026-11-20입니다. 기능과 플랜은 바뀔 수 있습니다.
- 환자 정보나 기관의 실제 데이터는 포함하지 않았습니다.

## 실행
`index.html` 파일 하나로 동작합니다. 브라우저에서 열거나 GitHub Pages로 배포할 수 있습니다. 글꼴은 Google Fonts를 사용합니다.
